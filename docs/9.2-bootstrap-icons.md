# 9.2 KMP icons

KMP uses one local SVG catalog combining Tabler Outline and Hugeicons Free Stroke Rounded.
Use canonical KMP identifiers and the shared helper, with decorative icons hidden and
informative icons named:

```php
echo $this->Icon->render('calendar', ['class' => 'me-1', 'size' => 20]);
echo $this->Icon->render('crown', ['label' => __('Royal Progress'), 'size' => 24]);
echo $this->Html->link(__('Download'), $url, ['icon' => 'download']);
```

Dynamic JavaScript uses `createIcon`, `iconHtml` and `setIcon` from `icon-service.js`.
Static markup may use `<kmp-icon name="search" aria-hidden="true"></kmp-icon>`.
Label the enclosing button or link when an icon is its only content. Use visible text
for status and actions where practical. Do not construct library CSS class names.

Controls default to approximately 20px; activity subjects use 24px and compact indicators
may use 16px. Both sources share a 24 × 24 grid, 1.5 stroke width, rounded joins/caps
and inherited text color. The picker searches names, labels, SCA keywords, upstream names
and exact legacy aliases, with one result per canonical entry and bounded batches.
Tabler is preferred for everyday application controls; useful overlapping SCA subjects
from both libraries remain available.

The Bootstrap Icons font/package is retired. Explicit aliases preserve recognized saved
identifiers, including header/footer class settings. No database conversion is required.
Unknown values are preserved and render a help-circle fallback. Historical migrations
and seed snapshots retain their original identifiers.

See the maintained [KMP icon implementation guide](../app/docs/icons.md) for pinned
sources, licenses, maps, PHP/JavaScript examples, picker behavior, asset delivery,
offline support, read-only saved-value inventory and reproducible update commands.
