## Current source map

- Plugin bootstrap: `app/plugins/Activities/src/ActivitiesPlugin.php`
- Controllers: `app/plugins/Activities/src/Controller/`
- Lifecycle service: `app/plugins/Activities/src/Services/DefaultAuthorizationManager.php`
- Workflow registration: `app/plugins/Activities/src/Services/ActivitiesWorkflowProvider.php`
- Workflow definitions: `app/config/Seeds/WorkflowDefinitions/activities-*.json`
- Policies: `app/plugins/Activities/src/Policy/`
- Tests: `app/plugins/Activities/tests/TestCase/`

Run targeted tests with `vendor/bin/phpunit plugins/Activities/tests/TestCase` from `app/`.
